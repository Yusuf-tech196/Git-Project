# Git Basics Guide

## Common Commands

Initialize a repository:
git init

Check repository status:
git status

Stage a file:
git add README.md

Commit changes:
git commit -m "Add documentation"

View commit history:
git log --oneline

Upload commits:
git push

## Best Practices
- Write meaningful commit messages.
- Review changes before committing.
- Do not commit passwords or access keys.
- Keep documentation accurate and up to date.
